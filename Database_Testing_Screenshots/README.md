TEST EVIDENCE

This folder contains selected visual evidence from the manual testing of a relational SQLite database.

The screenshots demonstrate practical verification of:

- Database structure and constraints;
- Valid data and database oprations;
- Relationships between related tables;
- Data updates and deletion;
- Handling of invalid data and constraint violations.


EVIDENCE CATEGORIES

'/POSITIVE'

Evidence of successful database operations and validation of valid data.

'/NEGATIVE'

Evidence of constraint enforcement when invalid data is provided.

'/FLOW'

Evidence collected during the end-to-end database testing flow.

Each screenshot is named according to the tested scenario,making the purpose of the evidence immediately identifiable.

Detailed test steps and expected results are available in the corresponding test case files.
